# 挑战闯关功能 CodeMap

更新：2026-11-09。挑战模块已实现，进入 Review。

## 入口与显示

- `src/main.js`：挂载应用。
- `src/app-shell.svelte`：主导航、页面切换、共享 `data`；`onMount` 调用 `loadData`，响应式调用 `saveData`。新增挑战页的接入点。
- `src/app.css`：深色背景、绿色强调色、可横向滚动导航、移动端布局。
- `src/pages/challenges-page.svelte`：六艺总览、十关路线、逐关标准、实际成绩录入、达成与解锁、历史删除；通过 `bind:data` 保存，通过 `bind:dirty` 告知主导航未提交的录入。
- `src/lib/challenge-catalog.js`：原书标准 `cc-v1`、60 关稳定 ID、目标组次/秒数、侧别、动作要点及来源页序。
- `src/lib/challenge-model.js`：成绩及标准快照、结构验证、逐组判定、路线进度、前置校验和删除；纯函数，可在 Node 中验证。
- `src/pages/train-page.svelte`：训练会话、逐组队列、成绩复盘及记录保存；现有记录未显式区分左右侧和动作质量。
- `src/pages/plans-page.svelte`：动作目录、计划编辑；动作以名称组织，没有稳定的囚徒健身动作目录 ID。

## 数据链路

`defaults() → loadData() → app-shell.data → 页面 bind:data → saveData() → localStorage`

- `src/lib/workout-model.js`：`defaults` 包含独立 `challenges: {version: 1, attempts: []}`；训练数据结构和工具沿用原有规则。
- `src/lib/data.js`：读取 `lianke_v3`（兼容 `lianke_v4`）、补齐旧数据，使用 `normalizeChallenges` 规范化挑战，再保存完整 JSON。
- `src/pages/settings-page.svelte`：导出完整 data；导入挑战时严格验证，遇到损坏/重复成绩拒绝本次导入；旧备份自动补齐空挑战；清空全部数据恢复默认挑战。
- `src/lib/cloud.js`：Supabase 逐表同步及本地选择性合并。下载以 `...localData` 开始，当前未知字段可被保留，但挑战不具备跨设备同步。
- `src/lib/init.sql`：保持原有云端表与 RLS 初始化；首版已确定仅本地及 JSON 备份，不添加挑战表或迁移。

## 可复用组件

- `src/components/select.svelte`：统一选择器。
- `src/components/time-picker.svelte`：时长输入。
- `src/components/confirm-dialog.svelte`：撤销等操作确认。
- `src/components/toast.svelte`：结果提示。

## 风险与验证

- 禁止按名称模糊匹配已有记录而自动通关；组数、侧别、动作质量均存在信息缺失。
- 新字段同时覆盖默认数据、本地读取、JSON 导入、清空路径；云端下载不得丢失本地挑战。
- 项目没有现成单元测试脚本，可用 Node 内置测试验证纯判定函数；按 frontend-no-build-validation 技能不运行 build。
- `tests/challenge-model.test.js`：15 项测试覆盖 60 行数据对照、判定边界、解锁/撤销、最终技与精英、备份/旧数据/云下载保留。命令 `node --test tests/challenge-model.test.js`。
