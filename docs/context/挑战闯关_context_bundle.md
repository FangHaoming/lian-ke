## Requirement Facts / Business Rules

- 本项目为 Svelte 4 + Vite，已有训练、计划、体重、统计、设置模块，本地保存并支持 JSON 备份及 Supabase 部分数据同步。
- 新模块应延续现有界面和持久化约定。
- 推荐首版六艺：俯卧撑、深蹲、引体向上、举腿、桥、倒立撑；每艺十关，路线独立推进。
- 必须区分次数与连续保持秒数、双侧与单侧、单组目标与整次挑战。
- 入门、中级、进阶/精英是不同标准；第十式不能把入门达成与精英达成混为一谈。
- 用户已确认（2026-11-06）：第十式达到入门标准即获得最终技成就并计入路线完成；精英标准及成就独立展示，不阻塞路线完成。
- 用户已确认（2026-11-09）：挑战成绩保留本地存储与 JSON 备份，并通过独立 Supabase 表可选同步。
- 60 式完整标准已核验：平卧蛙举腿进阶 3×25；单臂倒立撑精英每侧 1×5；桥最终式精英为 2×10–30，保留范围；倒立撑前三式为连续保持，桥十式为动态次数。
- 单臂倒立撑采用原书靠墙、允许腿部助力的定义，不能作为自由倒立无借力版本展示。
- 通关使用明确数据判定，并记录用户对动作质量的确认，属于自报成绩，不是机器动作认证。

## Proposed Acceptance Criteria

- 六条路线共 60 关，每关可查看名字、级别、目标组数、每组次数或连续秒数、是否要求左右侧、动作要点及来源。
- 一次挑战逐组达到目标才通过；单侧动作要求两侧分别达到；时长不可跨组累计。
- 失败保留成绩且不给通关；成功解锁本路线下一关，其他路线不受影响。
- 退出页面、刷新、JSON 导出再导入后成绩和解锁状态一致。
- 旧备份及云端同步不覆盖或损坏本地挑战数据。
- 挑战页明确当前浏览器本地保存；设置页提供挑战成绩云同步选项，使用独立云端表。
