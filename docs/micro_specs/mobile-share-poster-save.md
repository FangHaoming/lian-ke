# 移动端海报分享保存

- 目标：移动端点击“分享”时，能够把当前海报交给系统分享；不支持文件分享时，能够可靠打开海报图片供保存或分享。
- 范围：`src/components/challenge-share-dialog.svelte` 的海报分享与移动端兜底逻辑。
- 风险：移动端浏览器会拦截异步操作之后触发的新窗口或系统分享；验证使用静态检查和现有测试，不运行构建。
- 完成标准：分享动作在用户点击手势仍有效时调用 `navigator.share` 或打开图片窗口；现有桌面端下载和“保存图片”行为保持不变。

## 结果

- 已将分享文件从已生成的 data URL 同步构造，避免 `await toBlob()` 丢失点击手势。
- 不支持文件分享时改为同步打开海报窗口，并保留长按保存/系统菜单分享提示。
- 本次组件通过 Prettier；现有测试 21 项通过，`challenge-model.test.js` 的目录数据基准测试因现有 `79 !== 73` 失败，与本次改动无关。
