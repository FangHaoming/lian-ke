# Micro Spec: 删除远端数据增加密码验证

- 目标：删除远端数据前在确认弹窗中要求输入当前账号密码，并通过重新登录验证后才执行删除。
- 范围：`src/pages/settings-page.svelte`；不修改远端删除接口、数据库结构或账号注销流程。
- 方案：复用注销账号已有的 `authenticate('signin', ...)` 校验和错误提示；密码为空或验证失败时保留选择项并重新打开验证弹窗，验证成功后才调用 `deleteRemoteData`。
- 风险：验证失败不能误触发删除；通过代码顺序、格式检查和差异检查确认。
- Done Contract：删除远端数据弹窗显示密码框；无密码/错误密码不会调用删除接口；正确密码验证成功后正常删除。
