# 增量同步 micro-spec

## Goal

让挑战成绩、体重、训练记录和睡眠记录在本地与 Supabase 之间采用增量合并，不因一次同步覆盖或删除另一端已有数据。

## Scope

- 上传仅写入新增或发生变化的记录。
- 下载将远端记录与本地记录合并；同一 ID（体重按日期）去重并保留较新记录。
- 增量同步不执行远端删除；远端删除仍通过设置页的“删除远端数据”显式操作。
- 不改变计划、动作、提示音的既有同步范围和数据结构。

## Done Contract

四类数据在上传和下载路径均为增量合并；同一条记录不会重复；本地或远端独有记录不会因普通同步消失；定向测试与静态检查通过，不运行前端 build。

## Plan

1. 在 `cloud.js` 中增加四类数据的合并与变化检测。
2. 移除四类数据普通上传中的隐式删除，并更新同步结果计数与设置页文案。
3. 增加合并逻辑测试，执行现有业务测试、定向静态检查和差异检查。
