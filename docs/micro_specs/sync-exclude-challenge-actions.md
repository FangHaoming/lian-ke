# Micro Spec: 同步排除挑战页面动作

- 目标：普通数据同步不把挑战目录动作写入 `exercise_names` 动作表，下载时也不将远端已有的挑战动作回流到普通动作名称数据。
- 范围：`src/lib/cloud.js` 及同步测试；挑战成绩、训练记录和挑战页面功能保持不变。
- 方案：复用 `isChallengeExercise` 统一过滤上传和下载的动作名称；上传时同时清理此前已同步到动作表的挑战动作，避免遗留脏数据。
- 风险：动作名称过滤不能误伤普通自定义动作；通过挑战动作、普通动作混合的上传/下载测试验证。
- Done Contract：混合动作同步后 `exercise_names` 只包含普通动作，远端已有挑战动作不进入本地普通动作名称；现有挑战同步测试继续通过。

## Change Log

- 2026-11-10：通过挑战目录动作识别统一过滤 `exercise_names` 上传与下载；上传同步时清理远端历史遗留的挑战动作。

## Validation

- 新增同步测试通过；完整挑战测试中发现既有目录核验文档行数与固定断言不一致（79 vs 73），与本次改动无关。
