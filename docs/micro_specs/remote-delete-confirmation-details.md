# Micro Spec: 删除远端数据确认显示具体范围

- 目标：用户确认删除远端数据时，明确看到本次会删除的同步数据项。
- 范围：删除远端数据确认弹窗与共享确认输入组件；不改变实际删除范围和密码验证流程。
- 方案：让 `ConfirmDialogInput` 支持说明文字，在密码框前显示选中的数据项、未选中数据和本地数据不受影响的提示。
- Done Contract：删除远端数据弹窗可见地列出“将删除”的具体数据项，并保留不可撤销提示；账号注销弹窗不受影响。
