# 训练计划编辑页单返回按钮

- 目标：在管理计划的编辑训练计划场景中只渲染一个浮动返回按钮。
- 范围：由 `plans-page.svelte` 统一管理计划列表态和编辑态的返回入口；移除 `train-page.svelte` 的重复外层按钮。
- Done Contract：编辑态仅出现“返回计划”，列表态仅出现“返回训练”，两者仍分别返回正确的上一级页面。
- 验证：检查组件渲染分支与返回事件绑定，并运行与本次改动相关的非构建检查。

## 结果

- 变更：将“返回训练”按钮移动到计划管理页的列表态，并删除训练页外层重复按钮。
- 验证：Prettier 检查通过，`git diff --check` 通过；编辑态和列表态各自仅保留一个 `FloatingBackButton`。
- 限制：未执行生产构建，符合前端任务的非构建验证约束。

## 后续修复

- 问题：编辑态点击“返回计划”时，内部 `history.back()` 的 `popstate` 被误判为退出计划管理页。
- 修复：增加一次性 `leavingEditor` 标记，让内部返回只结束编辑历史记录，不触发列表态的“返回训练”。
