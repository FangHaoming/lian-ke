# Micro Spec: 从训练编辑器查看挑战动作

- 目标：在快速训练和训练计划编辑的动作卡片标题行中，对挑战页面动作显示“查看动作”按钮，点击打开对应电子书页，并能返回原页面。
- 范围：复用 `ChallengeActionLink`，通过挑战目录反查动作原文页码，生成带来源页面的电子书定位链接；普通自定义动作不显示，不改变训练数据格式。
- 风险：链接页码与挑战目录不一致或返回地址越界；直接使用目录中的 `sourcePage`，返回地址只允许应用内部的训练、计划和挑战页面，并保留新窗口打开以避免丢失未保存编辑。
- Done Contract：两处动作名称选择器均能对挑战动作显示可访问的查看按钮并定位到正确挑战详情；自定义动作不显示；格式、Svelte 解析和差异检查通过；不运行生产构建。
